Imadeo support

Help with the app and your own server.

Imadeo connects your photos and videos to a server you control. Find setup help here or contact the project maintainers through our public support form.

Contact support

Use the Imadeo support form on GitHub to report an app problem, ask a question or suggest an improvement. A GitHub account is required to submit a request. You can also browse existing support requests without signing in.

Support requests are public. Do not include passwords, authentication tokens, private server addresses, personal photos or other private information. Remove personal details from screenshots and logs.

Installation and connection help

The mobile app requires an Imadeo server and an account on that server. Follow the installation and product guide to set up the server, connect the app and configure remote access.

For connection problems, check that the server is running and that its address is reachable from your phone's current network. A home-network address normally needs the same Wi-Fi network or your own VPN.

What to include in a request

  • Your Imadeo app version, device model and operating-system version.
  • The Imadeo server version, if available.
  • The steps that trigger the problem and the error message you see.
  • A screenshot or log excerpt only after removing private information.

Accounts, stored photos and privacy

The person or organisation operating your server controls its accounts, stored media and backups. Contact that operator for help with your particular account or library. The Imadeo project cannot access or remove data from a privately operated server.

To delete your account, choose Delete account on the mobile app's Account screen. See the retention and deletion policy for the timing and effect on your server data and backups.

Read the Imadeo privacy policy for information about device permissions, server processing and external map services.
